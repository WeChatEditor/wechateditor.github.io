隐私与数据

本说明适用于桀士排版网站及“桀士排版·公众号助手”Chrome 插件，说明当前的数据用途、存储位置、权限和删除方式。

更新日期：2026 年 10 月 16 日 · 维护者：桀士 / JTLab

网站保存什么数据？

网站无需注册，不提供账号系统或云端草稿服务。当前应用没有内置广告、流量统计或将文章上传给维护者的业务接口。

  • 原稿、局部标注和必要图片数据：保存在当前浏览器的 IndexedDB 中，用于恢复当前草稿。
  • 主动创建的文章版本：保存在同一浏览器，用于查看、恢复和删除版本。
  • 排版配置、配色及固定头尾：保存在当前浏览器的 localStorage 中，用于恢复你的写作偏好。

这些内容不因使用不同设备而同步。浏览器清理、存储配额不足、隐私浏览模式或存储损坏都可能使保存失败或内容丢失；请留意保存提示，并自行备份重要原稿。

插件处理什么数据？

安装插件后，网页在本地保存成功时可以向插件同步当前文字排版。点击“发送到公众号”时，会额外提交本次传稿任务；自动同步本身不授权打开后台或插入文章。

  • 文章文字快照：包括标题、正文文字及排版 HTML，用于插件内复制或本次文章插入，保存在插件本地存储。
  • 账号和标签信息：读取公众号后台显示的账号名称及目标标签，用于选择、复核接收账号；选中的账号名称和标签标识可作为本地偏好保留，不随文字快照到期一并删除。
  • 任务与回执：保留本次执行所需的目标、阶段、提示和去重信息，避免重复写入或中断后自动重放。

插件不要求你把登录密码或 Cookie 提交给维护者，不把文章或账号信息发送到维护者服务器，也不出售这些数据。向公众号后台插入文字发生在你明确点击发送后；公众号保存及平台自身的数据处理遵循微信的规则。

插件中的可复制快照、任务和回执采用 24 小时有效期，到期后在读取或处理命令时清理；可复制快照也会被下次成功同步或发送替换。插件未运行时不承诺在到期瞬间执行删除。选中的账号偏好会持续保留，直至被更新、清理插件存储或卸载。

Chrome 权限分别用来做什么？

  • storage：保存短期文章快照、任务、回执和账号选择偏好。
  • scripting：在公众号后台执行账号识别、能力检查及你发起的文章插入。
  • mp.weixin.qq.com：访问公众号后台，识别目标账号与编辑页面，辅助新建和插入文字。
  • wechateditor.github.io：连接桀士排版工作台，接收网页的文字排版与传稿请求。

当前生产插件只申请上述两个网站的访问权限，不申请任意网站访问或浏览历史权限。你可以在 Chrome 扩展管理页面查看、限制权限或移除插件；限制权限后，相应连接、识别或传稿功能可能不可用。

哪些操作会产生网络请求？

打开网站时需要向 GitHub Pages 获取网页、脚本、样式和图标，托管方可能依据其政策处理 IP 地址、访问时间等请求信息。图片预览或复制准备可能请求你文章中引用的远程图片地址，图片来源方也可能接收这些请求。

插件打开公众号或你访问 GitHub 下载、反馈页面时，会与对应服务建立连接。剪贴板只在你点击复制或发送时写入；自动保存同步不会改变系统剪贴板。

产品介绍、排版教程和本隐私页均为静态说明，不读取你的草稿、配置或插件内容。外部网站有各自的数据处理规则。

如何备份或删除？

  1. 备份原稿：在编辑区复制重要 Markdown 到你自己的文件。文章历史、配色与固定头尾不会自动成为跨设备备份。
  2. 删除文章版本：在工作台“历史版本”中删除指定版本；这不会同时清空当前草稿或排版配置。
  3. 清理网站数据：在浏览器网站设置里清理 https://wechateditor.github.io 的站点数据，可移除该来源的草稿、版本和配置。关闭相关编辑标签后再清理，避免页面重新写入。
  4. 清理插件数据：移除插件可删除插件本地保存的快照、任务及偏好。网站数据与插件存储分别独立，清理其中一处不会自动清理另一处。

清理网站或插件数据前请先备份。上述操作不会删除已经粘贴、保存到公众号后台的文章，也不会清除其他应用已读取的系统剪贴板内容。
