使用教程

Markdown 如何排版到微信公众号

先写原稿，再调整样式，最后把排版带到公众号后台。这篇教程使用桀士排版的现行按钮名称，你可以边读边打开工作台操作。

1. 写下或导入 Markdown 原稿

打开写作工作台，在左侧“原稿”区域输入文字，右侧“公众号预览”会随内容更新。首次打开会显示可编辑的新手示例；浏览器已有草稿时，会优先恢复原来的内容。

你也可以使用原稿标题栏的导入入口，选择一个 UTF-8 编码的 .md 或 .txt 文件。单个文件不超过 2MB，正文不超过 50 万字符。 

# 一篇文章的标题

先用一段话，把你最想说的事情讲清楚。

## 第一个小节

用 **加粗** 标记重点，用列表整理并列的内容。

> 引用可以留给一句值得停下来读的话。

- 一个具体的观察
- 一个可以执行的建议

原稿支持标题、强调、列表、引用、表格和代码块。代码块用于展示内容，不会执行；直接输入的 HTML 不会作为网页运行。

2. 选择配色，调整标题与文字

打开顶栏“配色”，先挑一组适合文章的方案。18套默认配色覆盖朴素、自然、科技、复古与撞色风格；你可以继续调整正文色、强调色和其他角色颜色。

  • 标题样式：选择章节装饰、编号和左中右对齐，查看标题与正文的层级。
  • 文字设置：调整字号、行距等参数。字号范围为 11 至 32px，优先保证长段落读起来舒服。
  • 固定头尾：为常用的开场、作者介绍或结尾设置独立片段，再按需启用。

已有的配色列表会保留。想恢复新版18套默认方案，需要在配色面板确认“重置所有配色”；重置前先考虑是否保留自己的配色。

3. 在公众号预览里通读文章

使用“手机 / 电脑”切换阅读视图，按需打开“阅读外壳”。这些外壳和模拟公众号信息只用于查看，不会混入复制的文章正文。

长文章可以打开“同步滚动”，对照原稿与预览检查。复制前重点看小节层级、段落间距、表格宽度、代码块、强调色，以及固定头尾是否符合本篇文章。

工作台适合桌面浏览器，最小宽度为 800px。手机阅读视图是桌面工作台中的预览模拟；本教程可以直接在手机阅读。

4. 复制排版，粘贴到公众号正文

  1. 点击“复制到公众号”，等待成功反馈。如果按钮提示“复制已准备内容”，再次点击完成剪贴板写入。
  2. 打开微信公众号后台，新建或进入你要编辑的文章。
  3. 将光标放在正文编辑区域，再粘贴排版。文章标题栏需要单独填写。
  4. 检查正文格式、图片、链接和头尾，再在公众号后台手动保存。

安装插件后，顶栏主要按钮可能显示“发送到公众号”，旁边的复制按钮仍可复制排版；也可以在插件面板复制文字正文和标题。见Chrome 插件安装与传稿说明。

网页复制可能需要先准备图片。远程图片受来源跨域权限影响，无法读取时会提示失败；请根据提示处理图片，不要把预览可见当成复制成功。带图片文章使用网页复制流程，插件当前不接收含图文章。

5. 在公众号里做最后一遍检查

公众号可能调整粘贴后的样式，不同设备的字体也可能不同。保存前逐项确认：

  • 标题与正文是否完整，图片是否需要重新上传；
  • 标题装饰、表格、代码、列表和颜色是否符合预期；
  • 文章链接、封面、摘要和作者等后台字段是否已补全；
  • 用公众号自己的预览功能检查手机效果，再手动保存或发布。

本地草稿与历史版本怎么用？

正文会自动保存到当前浏览器。需要留一个明确的修改节点时，打开“历史版本”主动创建版本；自动保存不会替你无限新增历史。

排版配置和固定头尾单独保存，恢复某个文章版本不会回滚这些设置。没有账号和云端同步，换设备、换浏览器或清除网站数据后不会自动恢复原稿。重要内容请保留原始 Markdown 备份，完整说明见隐私与本地数据。

常见问题

复制按钮没成功，应该怎么办？

确认使用 HTTPS 或本地开发安全环境，允许浏览器剪贴板权限，并保持当前页面激活。如果图片准备失败，先处理提示的图片来源；如果内容已准备好，再次点击复制。

为什么插件插入后还要手动保存？

插件辅助将文字排版放入文章编辑器，不代替你检查内容，也不自动发布。后台页面变化、登录状态或账号识别都可能导致自动插入停止，此时可以使用插件内复制。

原稿突然进入冲突提示怎么办？

同一浏览器多个编辑标签可能同时访问一份草稿。出现冲突后按提示关闭冲突标签，避免同时修改；这些静态帮助页面不会读写草稿。
