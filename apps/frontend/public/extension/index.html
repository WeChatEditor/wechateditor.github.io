可选的 Chrome 传稿助手

把文字排版带到公众号

配合桀士排版网页，插件可以保留最新同步的文字排版，供你复制正文与标题；也可辅助在公众号后台新建文章并尝试插入。

查看安装步骤打开写作工作台 ↗

当前版本 0.1.12，适用于桌面 Chrome 120 及以上。插件处理文字排版；含图文章使用网页“复制到公众号”。自动插入可能因后台页面变化停止，请核对后手动保存，不会自动发布。

安装后可以做什么？

  • 同步文字排版：网页本地保存成功后，把当前文字排版同步到插件。同步本身不打开公众号，也不修改剪贴板。
  • 复制正文与标题：在插件面板点击“复制到公众号”或“复制标题”，再到公众号对应位置粘贴。
  • 辅助新建文章：在网页点击“发送到公众号”，插件尝试打开后台、新建独立空文章并插入本次文字快照。
  • 插入失败时继续复制：自动插入未完成，也可以从插件面板复制已同步的文字，无需重新触发传稿。

网页本身就支持编辑、预览和复制，插件按需安装。原稿、排版配置与历史版本仍由网页保存，插件不提供独立写作编辑器。

如何手动安装 Chrome 插件

当前提供安装包手动加载方式。请从本项目的构建页面获取安装包：

前往 GitHub 构建页面获取安装包 ↗

  1. 登录 GitHub，选择最新一次检查成功的 master 分支运行，在运行详情底部的 Artifacts 下载 jlab-wechat-transfer。GitHub 工件有保留期限；若已过期，可按下方源码方式构建。
  2. 解压下载文件；若里面还有 jlab-wechat-transfer-版本号.zip，继续解压，直到能直接看到 manifest.json。核对安装包版本为 0.1.12 或更新版本。
  3. 在 Chrome 菜单进入“扩展程序 → 管理扩展程序”，打开“开发者模式”。
  4. 点击“加载已解压的扩展程序”，选择直接包含 manifest.json 的目录。
  5. 按需固定工具栏图标，然后刷新桀士排版网页和已打开的公众号后台。

如果通过源码构建，在项目中安装依赖后运行 pnpm package:extension，加载生成的 apps/extension/dist/production 目录。开发环境要求与详细说明见项目源码与文档 ↗。

更新手动安装的插件时，用新安装包替换原目录内容，在扩展管理页面点击重新加载，再刷新网页与公众号后台。手动安装不会从商店自动更新；仅保留一份安装，避免版本混用。

从网页发送一篇文字文章

  1. 在网页工作台完成文字原稿与排版，等待本地保存。插件连接成功后，可在保存状态提示里查看同步结果。
  2. 点击“发送到公众号”。插件尝试打开公众号后台，使用已选择的有效账号或第一个可用账号；没有登录时先由你完成登录。
  3. 插件依次寻找“草稿箱 → 新的创作 → 文章”，只向本次新建的空文章尝试插入标题与正文。执行期间请等待，手动操作可能中止本次插入。
  4. 在公众号里检查标题、正文和排版，补充封面、摘要等字段，再手动保存，并使用公众号预览核对最终效果。

自动保存只更新插件可复制内容，不改变已经发送出去的任务。再次点击发送可能新建另一篇文章；失败后请先检查后台现状，不要连续重送。

自动插入没有完成时

打开 Chrome 工具栏上的插件面板，使用“复制到公众号”或“复制标题”，再手动粘贴到后台。正文复制保留文字排版；系统剪贴板只在你点击复制或发送时更新。

如果未识别账号，先在后台完成登录，再在插件的公众号选择器旁刷新。账号变化、编辑器非空、页面入口变化或接口未就绪时，自动插入会停止，请按具体提示处理。

如果网页当前含图，或本次同步失败，插件可能仍保留上次成功的文字快照。复制前核对内容，含图文章直接使用网页复制流程。

权限与数据

插件使用本地存储保留短期文字快照及任务信息，在桀士排版网页和微信公众号后台之间完成连接；脚本执行权限用于后台账号识别和文章插入。当前只申请这两个网站的访问权限。

可复制文字快照在 24 小时到期或下次成功同步、发送时清理或替换；到期检查在插件读取或处理命令时执行。卸载或清理插件数据会丢失其中的内容。详见隐私与数据说明。

仍然遇到问题？

请在项目反馈页 ↗说明 Chrome 版本、插件版本和提示文字。可以描述操作步骤，请勿公开文章原稿、账号标识、登录凭据或完整公众号后台网址。
