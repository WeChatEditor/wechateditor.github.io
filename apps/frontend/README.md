# 桀士排版 · Markdown 公众号排版助手

0.1.6传稿交互验收：无插件时右侧复制主按钮/左侧带tooltip发送图标，已连接时右侧发送主按钮/左侧复制图标；发送同次复制HTML/纯文字，复制和插件分别反馈。未安装/旧版显示安装或更新提示，重新检测后可切换主按钮，面板入口未连接时禁用。人工检查发送抽屉间距、长标题及公众号浮层换行导航、拖动/取消/键盘/缩放/收起。工程检查与安装包不代替这些实际验收。

JLab WeChat Editor 是独立 Vue 3 / Pinia / Element Plus / Vite / TypeScript 纯前端单页，保留桌面双栏（最小工作台宽度 800px）。顶栏空间不足时内部横向滚动；低于 800px 时页面横向滚动。

```powershell
pnpm --filter @jlab-wechat-editor/frontend dev
pnpm --filter @jlab-wechat-editor/frontend typecheck
pnpm modules:check
pnpm --filter @jlab-wechat-editor/frontend build
pnpm --filter @jlab-wechat-editor/frontend preview
```

开发地址 http://127.0.0.1:5175，构建预览 http://127.0.0.1:4175。静态部署 apps/frontend/dist；相对 base 支持子路径。请使用独立 HTTPS origin，与管理系统隔离。支持具备 IndexedDB、ResizeObserver、PointerEvent、ClipboardItem 的现代桌面 Chrome/Edge；复制需安全上下文。当前生产来源为https://wechateditor.github.io/，SEO规范网址和404链接按此根路径配置。

## 使用

- 单层顶栏直接调整正文色、强调色；选中右侧普通正文后，在气泡内选择固定字色或手动调色。
- 文字设置、标题样式、配色、固定头尾依次从左侧打开覆盖式 Element Plus Drawer，不挤压主页面，修改实时生效。
- 拖拽分隔线调整两栏，聚焦手柄可用左右键/Home/End；专注预览保留原比例。
- 单文件导入限 UTF-8 `.md`/`.txt`，2 MB / 50 万字符。原始 HTML 按文本显示，基础 Markdown 支持标题、强调、引用、列表、代码、表格、图片与链接。
- 导入在原稿标题右侧；手机/电脑宽度 radio 和专注预览在带图标的公众号预览标题右侧。章节按钮打开可滚动列表，点击立即选择。
- 插图和下载功能已移除；Markdown HTTPS 图片和旧草稿本地图片仍可显示。相对图片路径不会自动访问目录。
- 配色、标题样式、字体间距、固定头尾、比例、预览模式和局部颜色选择器偏好实时覆盖 localStorage，不保存配置历史。开头和结尾分别启用、编辑和清空；旧配置保留结尾，开头默认空且关闭。文章 Markdown、局部标注和必要旧素材 Blob 保存到 IndexedDB 的 current，修改后 450ms 自动覆盖。
- 顶栏「历史版本」打开左侧面板；点击「新增版本」按毫秒时间戳保存文章。支持倒序列表、原稿查看、确认后恢复与删除。版本不包含排版配置和固定头尾；恢复继续使用当前配置及头尾，不自动创建版本；需要保留当前文章时先新增版本。
- 保存状态统一在顶栏，事务完成才显示文章已保存；配置/文章失败分别提示，可点击「重试」。未知格式或多页面冲突暂停对应写入。旧完整草稿自动拆分迁移，配置写入失败时保留旧记录。
- 原稿和排版预览默认独立滚动，预览顶部「同步滚动」开启后按正文块源行锚点双向平滑联动。同步、阅读外壳与专注均用按钮active背景表示状态，点击切换且支持键盘，禁用时不响应。相邻正文块内插值，图片和固定头尾占用的空间按局部锚点处理。专注/恢复期间暂停同步，关闭立即停止。
- 仅启用阅读外壳且选择手机时，模型上方横排「自适应 / 原始大小」radio button与「当前缩放比例: N%」，窄栏保持单行可横移。默认自适应；原始大小保留所选375/390/414px视口宽度与CSS字号，在视窗内壳体中滚动长文，窄栏可横向滚动。1:1仍受浏览器/系统缩放影响。缩放与同步偏好仅驻留本页，刷新回默认。
- 底部左侧显示排版文字非空白字符数（包含启用头尾）及按 600 字/分钟估算的阅读时长，右侧保留作者桀士和项目GitHub链接，并增加产品介绍、排版教程、传稿插件和隐私说明。说明在新标签打开，不读取草稿；状态栏保持35px，窄宽度可横向滚动。浏览器存储提示收进顶栏保存状态的悬停说明。

- 改稿后无法确定的局部标注会失效；再次选择文字即可重设。需要备份时手动复制原稿到本地文件。
- 复制包含 HTML 和纯文字；图片失败会阻止复制。权限拒绝后可点击「复制已准备内容」重试。站外链接转换为可见网址。
- 复制成功显示绿色「已复制 ✓」2.5秒后自动复位为「复制到公众号」，连续复制重新计时。固定结尾片段按钮追加成功时自动启用结尾并保留旧内容，修改即时保存。

初始化18套、总计1至24套的可编辑配色与12款标题样式为独立实现，参考编辑式排版方向。新配置默认青黛朱砂、杂志刊头与章节编号。Markdown标题参与章节样式，TXT不自动猜章节。微信输出仍为 `wechat-clipboard@0.1-candidate`，实际公众号效果由人类验收。

## 人工验收

卡片验收：无current时，默认文章以“把想法，排成好文章”封面开场、三项总结卡收尾，正文展示简短Markdown与分段，已有或空current不被覆盖。原稿工具栏“封面卡”“总结卡”可插入和转换选中行，检查IME、撤销、全文/行末选区、长度限制和锁定。标题样式抽屉底部设置符号与品牌，修改/清空/刷新恢复；旧配置缺失字段能读取，损坏值保留原记录并暂停保存。切换配色、11至32px字号、手机/电脑、长标题/链接、加粗、嵌套列表、有序列表、普通/未知/不完整引用及代码里的标记。卡片内部标题不抢章节编号；局部改色、原稿同步和历史列表标题可用。富文本/纯文字/插件文字输出不泄漏类型标记、不重复列表符号；公众号粘贴/保存/明暗人工确认。见[计划](../../docs/plans/active/2026-10-19-markdown-cards.md)。

暖纸与代码主题验收：工作台整体暖灰、编辑/预览柔白纸面、右侧画板较深，标题/工具条/抽屉/调色弹层背景与边框保持一致。手机/电脑、开关外壳、缩放/同步/专注与原有布局逐项检查。切换18套配色及手调颜色，核对代码块背景/文字/边框/三圆点、行内代码及标题内代码；深色或低对比度自定义背景仍应有可读代码前景。引用底色关闭不影响代码主题，长代码/空行/符号/缩进保持，复制、插件快照、公众号粘贴/保存/明暗效果分别验收。设计与实施见[计划](../../docs/plans/active/2026-10-19-themed-code-warm-workspace.md)。

编辑式配色验收：新配置默认18套、三列六行、青黛朱砂/杂志刊头/编号开启。逐套检查标题、正文、强调、引用底色开关、表头及手机/电脑长文；原九id与用户旧列表/颜色保留。重置取消不写，确认恢复18套且当前文章颜色不变，点击卡片应用。18套可新增6套，满24套禁用新增，删除最少一套，保存后刷新仍能读取18至24套。12款标题两列六行，逐款检查长标题、内含加粗/链接/代码、三种对齐、紧贴与编号，以及公众号复制、保存、明暗模式。

字号扩展验收：文字设置11至32px滑杆/键盘调节及九个快捷档，窄抽屉按钮自动换行；11px、32px和中间档实时预览、刷新恢复，旧14至18px配置及原有合法小数记录可读；文字重置回16px，公众号复制/保存重开效果单独确认。

新增验收：375/390/414px手机档位（宽度为阅读视口，外壳另加边框）、开关外壳/自适应/原始大小/窄栏横移与同步；原稿上下浅灰只读头尾启停/空内容/长内容内部滚动，正文不混入头尾。全站逻辑CSS字号至少11px，标题辅助行变大后48px栏高及800px工作台仍可用。两标签分别修改文章或配置、事务writeId冲突时显示“当前页面自动保存已暂停”，全部工作台/抽屉/键盘操作锁定、旧异步导入不可应用；确认关闭本标签，浏览器拒绝时保持弹窗并提示手动关闭。普通配额/权限失败仍可重试。

插件自动同步验收：更新0.1.6后修改正文/标注、只改排版/头尾或恢复历史，保存完成后显示“插件已同步”，面板可复制最新标题/文字排版。自动保存不打开后台、不触发新建插入、不写系统剪贴板、不改变已发任务。无插件、旧版、图片、空正文、超限、配额或权限失败不妨碍本机保存，悬停保存状态可查看插件未同步原因；多页冲突/恢复/卸载不发新的同步。实际复制排版和公众号手动保存仍由人类验收。

2026-10-11新增：顶栏正文色/强调色分别修改对应角色；选区气泡“手动调色”保留选区，HEX/色板/取色器确定应用、取消不应用。电脑开关阅读外壳都按正文最大677px居中留白。同步以标题/段落等块源行锚点双向映射，检查长段落、列表、表格、代码、图片加载、启用头尾、顶部/底部、空/短文及调整宽度和手机zoom后无回环。配色更新/删除确认取消不写、确认生效并刷新保留，最少一组；改名弹窗始终在抽屉上方。底部作者及GitHub链接可访问。

# UI 与阅读交互改造

现行工作台采用52px顶栏、统一应用tokens、配色最大640px且固定三列、固定头尾/标题样式/历史版本最大520px、文字设置最大320px左侧覆盖抽屉。18套配色呈3×6，卡片右上角动作图标在hover/focus显示并带tooltip；正文/局部色不显示hex，所有调色面板“清除/确定”且单焦点边框。原稿/预览标题统一48px，窄预览工具横向滚动。标题/配色为实际预览卡片，文字设置支持快捷档。手机与电脑均有可关闭阅读外壳，模拟元信息不进入文章标注或复制。有效正文选区显示改色/清除气泡，固定头尾不参与编号或局部标注；预览与复制按开头→正文→结尾组合，统计包含启用头尾。快捷格式改Markdown，清除命令只移除颜色标注。最近颜色独立保存，读取失败不影响草稿。悬浮Toast不改变工作区高度，完整诊断可重新打开，保存失败持续保留顶栏状态。

输出含内联终端代码块、便签引用、表头/斑马纹；结尾片段由用户显式追加。既有配置与草稿保持兼容，新配置默认青黛朱砂/杂志刊头/编号开启。技术验证不代替人工UI与公众号验收。新增人工验收：手机/电脑外壳启停与专注、缩窄分栏时文字设置钳制编辑栏、宽抽屉可覆盖部分预览、跨强调/链接选区、色板内操作不丢锚点、局部清除两侧保留、IME/撤销/快捷格式、无布局位移反馈，以及公众号粘贴后的代码/引用/表格/结尾和明暗模式。

人工验收调整：章节序号独立；配色初始化18套、总计1至24套，均可改名、更新颜色和删除，显式重置恢复18套。已有current包括空稿都不覆盖，新用户默认稿串联封面、Markdown正文和总结卡，可比较标题、强调、引用、表格与代码的主题颜色。请验证手机/电脑滚动、125%缩放、改名删除与刷新、编号开关及600字/分钟统计。

第二轮人工验收：配色卡片悬停或键盘聚焦显示更新颜色、修改名称、删除；名称弹窗支持预填、非空1至30字符校验、保存/取消及刷新恢复。导入对齐原稿标题栏右侧；章节和历史版本抽屉最大520px；方括号编号为 [01]，关闭为 [ ]，卡片、文章与复制共用规则。预览不显示画板尺寸或复制效果提示。
