# 桀士排版 · Markdown 公众号排版助手

JLab WeChat Editor 是独立 Vue 3 / Pinia / Element Plus / Vite / TypeScript 纯前端单页，保留桌面双栏（最小工作台宽度 800px）。顶栏空间不足时内部横向滚动；低于 800px 时页面横向滚动。

```powershell
pnpm --filter @jlab-wechat-editor/frontend dev
pnpm --filter @jlab-wechat-editor/frontend typecheck
pnpm --filter @jlab-wechat-editor/frontend architecture:check
pnpm --filter @jlab-wechat-editor/frontend build
pnpm --filter @jlab-wechat-editor/frontend preview
```

开发地址 http://127.0.0.1:5175，构建预览 http://127.0.0.1:4175。静态部署 apps/frontend/dist；相对 base 支持子路径。请使用独立 HTTPS origin，与管理系统隔离。支持具备 IndexedDB、ResizeObserver、PointerEvent、ClipboardItem 的现代桌面 Chrome/Edge；复制需安全上下文。生产域名本轮未指定。

## 使用

- 单层顶栏直接调整正文色、局部字色；选中右侧普通正文后再改局部颜色。
- 文字设置、标题样式、配色、固定头尾依次从左侧打开覆盖式 Element Plus Drawer，不挤压主页面，修改实时生效。
- 拖拽分隔线调整两栏，聚焦手柄可用左右键/Home/End；专注预览保留原比例。
- 单文件导入限 UTF-8 `.md`/`.txt`，2 MB / 50 万字符。原始 HTML 按文本显示，基础 Markdown 支持标题、强调、引用、列表、代码、表格、图片与链接。
- 导入在原稿标题右侧；手机/电脑宽度 radio 和专注预览在带图标的公众号预览标题右侧。章节按钮打开可滚动列表，点击立即选择。
- 插图和下载功能已移除；Markdown HTTPS 图片和旧草稿本地图片仍可显示。相对图片路径不会自动访问目录。
- 配色、标题样式、字体间距、固定头尾、比例、预览模式和局部颜色选择器偏好实时覆盖 localStorage，不保存配置历史。开头和结尾分别启用、编辑和清空；旧配置保留结尾，开头默认空且关闭。文章 Markdown、局部标注和必要旧素材 Blob 保存到 IndexedDB 的 current，修改后 450ms 自动覆盖。
- 顶栏「历史版本」打开左侧面板；点击「新增版本」按毫秒时间戳保存文章。支持倒序列表、原稿查看、确认后恢复与删除。版本不包含排版配置和固定头尾；恢复继续使用当前配置及头尾，不自动创建版本；需要保留当前文章时先新增版本。
- 保存状态统一在顶栏，事务完成才显示文章已保存；配置/文章失败分别提示，可点击「重试」。未知格式或多页面冲突暂停对应写入。旧完整草稿自动拆分迁移，配置写入失败时保留旧记录。
- 原稿和排版预览默认独立滚动，预览顶部「🔄 同步滚动」开启后按两侧滚动百分比双向平滑联动。固定头尾、图片和Markdown排版会使具体段落错位。专注/恢复期间暂停同步，关闭立即停止。
- 手机阅读外壳顶部显示缩放比例，默认「适应屏幕 (全貌)」；切换「1:1 真实像素 (壳内正常纵向滚动)」保留440px宽度与CSS字号，在视窗内壳体中滚动长文，窄栏可横向滚动。1:1仍受浏览器/系统缩放影响。缩放与同步偏好仅驻留本页，刷新回默认。
- 底部左侧显示排版文字非空白字符数（包含启用头尾）及按 600 字/分钟估算的阅读时长，右侧显示浏览器存储提示与产品信息。
- 改稿后无法确定的局部标注会失效；再次选择文字即可重设。需要备份时手动复制原稿到本地文件。
- 复制包含 HTML 和纯文字；图片失败会阻止复制。权限拒绝后可点击「复制已准备内容」重试。站外链接转换为可见网址。
- 复制成功显示绿色「已复制 ✓」2.5秒后自动复位为「复制到公众号」，连续复制重新计时。固定结尾片段按钮追加成功时自动启用结尾并保留旧内容，修改即时保存。

初始化六组、总计1至9组的可编辑配色、九种章节为独立实现，视觉取原研究方向，未声明与原站逐像素一致。明确 Markdown 标题参与章节样式，TXT 不自动猜章节。微信输出为 `wechat-clipboard@0.1-candidate`，未经真实公众号验收。

## 人工验收

此清单等待维护者执行，静态检查与构建不代替功能验收。

1. 800×720、1280×720、1440×900：工具栏单层，800px 时顶栏可横向滚动访问全部控件，双栏保留且页面不被顶栏撑宽；低于 800px 时页面可横向滚动。五个抽屉互斥且不挤压工作区，章节列表可滚动选择，设置实时生效。
2. 拖拽、释放、取消、失焦、键盘调比例；抽屉/专注开关后比例恢复。
   长文原稿、手机/电脑宽度预览及专注预览均能滚动到底；标题和底部信息持续可见。空文统计为 0 字/0 分钟；修改正文、代码及结尾启停时统计同步更新。
3. 中文输入法、单文件导入/UTF-8 失败与长度限制、代码 Tab 缩进。
4. 跨加粗/链接/段落选区改色；混选代码、图片、装饰或结尾整次拒绝；换主题不丢标注；改稿歧义提示。
5. 修改配色、字体、章节、结尾、比例、预览模式后立刻检查 localStorage 并刷新恢复；配置修改不增加历史、不写 current。正文修改后等待 450ms，确认 IndexedDB current 覆盖且历史条数不变。检查顶栏失败/暂停/完成及重试。
   主动新增多个版本（同毫秒/系统时钟回退亦不覆盖）、刷新倒序恢复、查看全文、取消恢复/删除、确认恢复（配置不回滚）与删除（current 不变）。恢复时禁用编辑，旧选区失效；历史只保留正文必要素材，当前结尾旧素材继续可用。模拟旧 schemaVersion 1 草稿迁移、新配置优先、localStorage/IndexedDB 权限或配额失败、未知格式/损坏记录保留、多页面并发暂停及事务冲突。
6. Markdown 图片和旧素材真实显示/尺寸、缺图、远程 CORS、GIF 动画/WebP/透明图及超尺寸提示。
7. 长代码不截断、表格换行、列表/嵌套/起始序号、站外 URL；手机/电脑 radio切换带阅读外壳的文章宽度模拟。
8. 剪贴板权限拒绝重试、准备中改稿不复制旧快照；TXT 接收纯文字，公众号接收富文本。
9. 公众号粘贴 → 保存再打开 → 微信明暗阅读，核对颜色、表格、代码、图片托管和文章完整性。记录账号、浏览器/微信版本、输出 profile 和缺失项。
10. 手机适应/1:1与比例提示、窄栏横移和壳内滚动到底；开关外壳、手机/电脑、专注、拖拽、125%缩放。同步默认关闭，开启后两侧可驱动且无回环，空/短/长文与图片加载、减少动态效果、切换布局均可用，关闭立即停止。结尾关闭后逐项追加片段应启用、保留旧内容及刷新恢复；复制成功绿色2500ms复位，连续复制/改稿/权限失败重试均可用。

# UI 与阅读交互改造

现行工作台采用52px顶栏、统一应用tokens、配色最大640px且固定三列、固定头尾/标题样式/历史版本最大520px、文字设置最大320px左侧覆盖抽屉。九个配色呈3×3，卡片右上角动作图标在hover/focus显示并带tooltip；正文/局部色不显示hex，所有调色面板“清除/确定”且单焦点边框。原稿/预览标题统一48px，窄预览工具横向滚动。标题/配色为实际预览卡片，文字设置支持快捷档。手机与电脑均有可关闭阅读外壳，模拟元信息不进入文章标注或复制。有效正文选区显示改色/清除气泡，固定头尾不参与编号或局部标注；预览与复制按开头→正文→结尾组合，统计包含启用头尾。快捷格式改Markdown，清除命令只移除颜色标注。最近颜色独立保存，读取失败不影响草稿。悬浮Toast不改变工作区高度，完整诊断可重新打开，保存失败持续保留顶栏状态。

输出含内联终端代码块、便签引用、表头/斑马纹；结尾片段由用户显式追加。既有配置与草稿保持兼容，新草稿默认清透蓝。技术验证不代替人工UI与公众号验收。新增人工验收：手机/电脑外壳启停与专注、缩窄分栏时文字设置钳制编辑栏、宽抽屉可覆盖部分预览、跨强调/链接选区、色板内操作不丢锚点、局部清除两侧保留、IME/撤销/快捷格式、无布局位移反馈，以及公众号粘贴后的代码/引用/表格/结尾和明暗模式。

人工验收调整：章节序号独立开关；配色初始化六组，总计1至9组，均可改名、更新颜色和删除，可重置为默认六组；配色与结尾抽屉加宽；往期精选需在公众号编辑器手动添加链接。请再次人工验证长文在手机/电脑完整外壳内滚动、关壳预览滚动、125%缩放、改名删除与刷新恢复、编号开关及600字/分钟统计。

第二轮人工验收：配色卡片悬停或键盘聚焦显示更新颜色、修改名称、删除；名称弹窗支持预填、非空1至30字符校验、保存/取消及刷新恢复。导入对齐原稿标题栏右侧；章节和历史版本抽屉最大520px；方括号编号为 [01]，关闭为 [ ]，卡片、文章与复制共用规则。预览不显示画板尺寸或复制效果提示。
