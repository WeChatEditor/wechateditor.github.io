# typesetting模块

2026-10-19编辑式视觉系统参考[研究](../../reference/editorial-color-study.md)，实施与人工验收见[计划](../../plans/active/2026-10-19-editorial-color-system.md)。

## 职责与边界

字号、间距、字体、颜色角色、配色列表、十二种章节样式与颜色控件。规则供预览和导出共用。

正文字号范围11至32px，滑杆步长1px，快捷档为11/12/14/16/18/20/24/28/32px，按钮自动换行；默认及重置仍为16px。范围与快捷档定义在公共typesetting.model.ts，workspace配置校验引用同一范围，旧14至18px记录完整兼容；已有合法小数记录继续接受，不改变存储格式。预览/复制沿用同一styleArticle按配置输出，标题字号继续相对正文计算。

共用颜色控件用Popover承载ColorPickerPanel，保留HEX输入、色板、横排常用/最近色。footer新增屏幕取色按钮，通过安全上下文中的浏览器EyeDropper响应用户点击；不支持时禁用并提示原因。取色与面板编辑仅更新内存草稿，确定才执行原change通道及最近色写入；取消或外部关闭放弃草稿。Esc取消取色保留草稿，非取消失败显示面板提示。关闭、禁用与卸载用AbortController中止操作，晚到结果拒绝应用。弹层保留el-color-picker__panel类以兼容局部正文选区保护，不访问其他模块私有状态。

章节样式为下划线/粗下划线（2/5px底线）、竖线/粗竖线（4/8px）、末尾斜线、围住完整标题的方括号/双圆/点阵。点阵左右各两列三行3px圆点，列间距3px、行间距2px，整体9×13px。序号可独立启用，位于装饰内并在标题前。紧贴标题默认启用，下划线跟随标题主体宽度（含启用的序号），其他装饰邻接标题主体；关闭时下划线为整行宽度，单侧装饰在对应行边、双侧装饰在左右行边。紧贴下划线由inline-block主体绘制，保留原底部间距，最大宽度100%，多行时按主体整体宽度绘制底线。标题主体包含序号和原始内联节点，按左/中/右对齐（默认左），长标题可换行；原始节点不重建，装饰用data-decoration标记，纯文字复制剔除装饰但保留正文。文章主标题和头尾不添加章节装饰。

非目标：本模块不增加账号、云存储或服务端API，不访问其他模块私有文件。当前文件位于apps/frontend/src/modules/typesetting。

## 公共接口与依赖

公共文件：`typesetting.model.ts`、`typesetting.service.ts`、`typesetting-panel.vue`、`typesetting-color-picker.vue`。跨模块仅导入这些文件，禁止barrel。允许依赖：无其他模块；禁止反向依赖与循环。登记来源唯一为根.module-boundaries.json。

## 数据流与失败模式

界面props/events → workspace命令 → 本模块公共服务/模型 → 预览/输出或持久化端口。配色总计1至24套，默认18套可修改/删除/重置；读取与写入校验共用maxPalettes，不再将读取限制在15套。超24套异常配置保留原记录并暂停保存。最近颜色偏好失败不阻断改色；设备字体和低对比度由人类验收。

新配置使用defaultPresetId=editorial（青黛朱砂），标题为杂志刊头、编号开启、左对齐、紧贴，正文16px/1.9行距/18px段距/0.5px字距；缺少palettes的旧配置补18套。已有列表、当前颜色、章节偏好完整恢复，不按id覆盖或自动补齐。normalize对旧缺省编号仍补false。确认“重置所有配色”复制18套默认数据、preset设为custom、当前文章颜色保留；取消不写。18套初始列表仍可新增6套，满24套禁止新增，删除至少保留一套。

配色卡片三列，白纸小样调用chapterPreview的杂志刊头样式，配以实际正文、引用与五角色色条、编号及已选/推荐标识；不新增描述段。更新/改名/删除继续只在hover或focus-within显示。推荐只按内置默认id标识，不改变用户已选颜色。

正文、标题、强调、引用在白底和本组浅底上静态对比度至少4.5；强调另核对行内代码固定底，标题另核对表头。此次最低约4.67。颜色计算仅证明数值，手机/电脑缩放与公众号粘贴仍需人工验收。

## 编辑式标题和阅读节奏

新增editorial（杂志刊头：衬线标题、1px底线、编号为1.25em Georgia）、label（色签标题：强调底色、7px×13px内边距、3px圆角）、frame（双线专栏：2px顶线与1px底线）、minimal（极简细线：1px左线、12px间隔、500字重），保留原八款。新四款紧贴时随内容宽度，关闭时满行；三种对齐、编号独立、换行及原始内联节点共用decorateChapter。色签前景根据强调色对白色对比度选择白/黑，标题中的加粗、链接和代码继承标题色，避免压过色签上的文字。字体为本机回退，实际字形由设备决定。

标题卡片改为两列，12款共六行，使用与文章相同服务。主标题不编号，字号为正文+12、行高1.4，第一块主标题去掉顶空白，浅色细线收尾；章节为正文+5，其余副标题为正文+2。章节间距26px/14px、行高1.5。引用使用2px强调边、12px×16px内边距、4px右圆角，清除引用与列表末尾段落的多余底距。表头取当前浅底，强调/行内代码/链接继续取强调色。全部为内联CSS，预览、剪贴板与插件文字快照共用，无CSS伪元素、图片或新解析语法。

配置格式、公共文件、模块依赖与存储所有权保持原状；新增枚举值通过现有chapterStyles校验，无需新增ADR。

## 配色确认与弹层

更新和删除卡片配色需MessageBox二次确认，取消不写入；确认时使用最新配置，删除仍须保留至少一组。待确认时禁止重复打开操作。名称prompt预填并保留原校验，body中的Overlay需显式导入el-overlay.css提供fixed定位，使用MessageBox自身递增z-index，避免位于配色抽屉下方。
