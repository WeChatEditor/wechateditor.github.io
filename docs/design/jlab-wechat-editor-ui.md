# 桀士排版工作台UI与阅读交互

2026-10-16底部状态栏增加产品介绍、排版教程、传稿插件和隐私说明的可聚焦链接，在新标签打开静态说明。作者、GitHub、字数和阅读时长保留；高度35px不变，窄宽度允许状态栏横向滚动。编辑器顶栏品牌继续“桀士排版”/“公众号助手”，描述性搜索标题只修改HTML元信息。独立说明页使用响应式静态样式，见[搜索发现设计](search-discovery.md)。

2026-10-21品牌旁增加“免费 · 开源”链接，使用现有主色与active浅底、至少11px字号、独立键盘焦点，指向新标签./about/#open-source。保留52px单层顶栏与内部横向滚动；底部GitHub链接文字明确为“开源代码 ↗”。产品页首屏以三个文字标签突出免费使用、MIT开源和无需注册，后续三张说明卡使用既有响应式网格；源码与LICENSE均可直接访问。页面阅读、800/1280/1440px顶栏布局和链接体验由人类验收。

## 插件连接与发送反馈

启动一次检测插件。已连接时右侧蓝色“发送到公众号”主按钮、左侧32px复制图标；未连接/不兼容/检测中时右侧蓝色复制主按钮、左侧32px发送图标。图标保留aria-label与hover tooltip，检测中或缺失仍可点击发送进入安装提示，复制/发送忙时禁用重复操作。

发送抽屉在点击时打开，保持520px左覆盖边界；内容有22px内边距与18px分组间距，标题自动换行，连接卡片含重新检测和安装说明，复制/插件接收结果分别显示，按钮为两列可收缩布局，底部提供后台入口和三步操作说明。打开传稿面板检测中、无插件、版本不兼容时禁用。点击发送同次尝试富文本复制和插件传稿，二者成功分别报告；含图沿用完整复制，自动插入仍是文字首版。真实布局、clipboard、Chrome和公众号功能由人类验收。

## 手机档位、冲突与原稿头尾

手机模式提供“iPhone 390px / 标准手机 375px / 大屏 414px”，默认390×844，另外375×812与414×896逻辑视口。壳体宽度另加6px边框，关壳也使用所选宽度；手机档位控件始终在模型上方，适应/原始大小与比例提示仅开壳时显示，窄栏单行横向滚动。档位为当前页面内存偏好，不改配置格式。工作台和弹层CSS字号至少11px，辅助标题调至11px并放松字距；手机预览的视觉缩放仍由模拟zoom控制。

固定头尾设置提供“在原稿中显示固定头尾”开关，默认开启并保存到当前浏览器；关闭仅隐藏左侧只读块，不影响头尾实际启用、预览、复制和统计。开启时，原稿格式工具下方与正文底部显示启用的固定开头/结尾，只读浅灰块含名称、“只读”标识及原始Markdown文本，空内容有提示；单块内容最长80px并独立滚动。头尾不进入textarea，不参与正文选区/撤销/历史，修改仍通过固定头尾设置。

多标签文章/配置冲突显示原生顶层Modal，主标题“当前页面自动保存已暂停”，明确另一标签已更新及本页全部操作锁定。Esc与遮罩不能关闭；关闭抽屉和其他弹窗，工作台inert且store阻止新保存/修改/历史/复制，取消待保存及晚到异步应用。唯一确认按钮尝试关闭当前标签页；浏览器拒绝则保留Modal并提示手动关闭，页面保持锁定。普通存储损坏或配额失败继续原恢复/重试流程，不误判为标签冲突。

## 2026-10-11交互修订

顶栏以“强调色”替换局部字色，修改colors.accent并使用custom配色；局部字色只在选区气泡操作，固定色之外明确显示“手动调色”，共用HEX/色板/取色器及取消/确定。电脑正文与阅读元信息最大内容宽677px，居中并保留两翼留白，外壳可宽于正文，关闭外壳时同样限制正文宽度。

同步采用正文块Anchored Scroll：解析块保留源行号，原稿镜像按textarea实际字体/宽度/换行测量行坐标，预览测量对应块坐标（扣除手机zoom）。相邻锚点内插值双向映射，顶部/底部作为边界；同源行只取最外层块，隐藏块不参与。固定头尾与阅读元信息不生成正文锚点，其空间包含在正文前后边界。内容、图片、模式或尺寸改变后重新测量对齐，保留防回环及减少动态效果。空文/短文和无滚动范围钳制到边界，不以全文高度比例代替有块的映射。

配色更新与删除弹出带名称的确认，取消/关闭不写入；确认后读取最新配置，至少保留一组。改名与确认弹窗使用Element Plus共享递增层级，挂载body并位于抽屉之上。底部显示“作者：桀士”和指向本项目仓库的GitHub链接，新标签页打开。

底部仅显示左侧字数/阅读时长与右侧作者/GitHub。“数据仅保存在当前浏览器”收进顶栏保存状态的title悬停说明，与当前保存状态一起展示，不再单独占据底栏中央。

改名MessageBox的Element Plus输入框只保留外层wrapper的焦点边框，内层input的focus-visible不叠加工作台通用outline。该例外限定MessageBox输入，不移除原稿、原生输入或按钮的键盘焦点提示。

## 网站图标

浏览器图标使用蓝白配色的纸页与字母 J 图形，沿用工作台主色 #2563EB。图形保持粗线条和少量排版横线，适合小尺寸标签页。生成原图与提示词保存在 docs/reference/brand/；应用 public/ 保存多尺寸 favicon.ico、32px/192px PNG 和 180px Apple 图标，HTML 使用相对路径，兼容 GitHub Pages 仓库子路径。图标不影响文章导出、界面标题或存储协议。生成素材需人工确认视觉；允许的验证为资源尺寸、ICO 结构、生产产物及静态工程检查。

## 空间与视觉

2026-10-19[暖纸工作台](../plans/active/2026-10-19-themed-code-warm-workspace.md)以设计板#f7f5f1和现行About#f6f5f1为依据：ui-bg=#f7f5f1暖灰，ui-surface=#fcfbf8工具/抽屉，ui-paper=#fffdf8编辑/预览纸面，ui-canvas=#ebe7df画板，ui-chrome=#f2efe8手机导航/电脑工具条。预览画板采用155度ui-bg至ui-canvas的轻渐变，68%进入画板色；暖灰边框#dedbd3，正文#26343b，辅助文字#5e6966，悬停底#efede7。辅助文字在最深画板上的静态对比度约4.62。蓝色交互主色#2563eb和active状态保留。Element Plus弹层/输入/抽屉背景与边框映射到同一tokens，原稿工具/标题条和状态栏用surface，textarea在paper上编辑。手机金属边框、电脑边框与阴影采用暖灰，保留真实黑色灵动岛/底条。文章外壳开关、手机/电脑模式均使用相同柔白纸面，布局、宽度、滚动与缩放不变。

应用tokens保持workspace私有所有权，article组件仅使用统一CSS变量；UI纸面和画板不进入文章输出。文章代码背景单独依当前主题由typesetting内联生成，详见[排版模块](modules/typesetting.md)。

沿用来源完整UI。52px单层顶栏：品牌、正文色/强调色、设置、保存与复制；不足时仅顶栏内部横向滚动。800px最小宽度，编辑建议最小280px、预览320px，双栏比例以容器动态钳制而不覆盖用户偏好。分隔手柄无占位列、支持Pointer capture/取消/失焦与键盘。网格和flex零最小高度，原稿和预览独立滚动，标题/状态栏保留。

应用tokens归workspace私有样式；中性底色、蓝交互强调与状态色不进入文章导出，文章主题独立。底部非空白文字计数与600字/分钟估算包含启用头尾，首次示例稿按实际内容计数；正文及启用头尾为空时为0字/0分钟，保存状态集中顶栏。

共用ui-button的active背景与主色文字在hover时保留，避免已选状态被普通hover底色覆盖；预览两组radio button使用实心主色背景、白色文字及主色边框，hover时保留选中态。

## 抽屉与排版

所有颜色弹窗在HEX输入旁提供“取色器”按钮，屏幕取色结果先回填面板，点击“确定”才应用。取消或外部关闭放弃本次调整；Esc可退出屏幕取色并继续编辑面板。按钮取色期间显示“取色中…”并禁用，不支持屏幕取色的浏览器/上下文显示禁用原因，HEX与色板继续可用。失败在面板内提示，关闭/禁用/卸载中止取色。正文色、强调色、选区手动调色和配色角色共用同一控件，局部正文选区在面板操作期间保留。

无遮罩、不锁页面滚动的左覆盖Drawer位于顶栏下到状态栏上，一次一个，支持Escape/关闭/重复点击，关闭不回滚设置。配色最大640px，固定头尾/标题样式/历史最大520px，均钳制工作区减40px；文字设置最大320px并钳制编辑栏。工具依次文字设置、标题样式、配色、固定头尾；正文色/强调色只显示色点和名称。所有调色面板按钮“取消/确定”，输入框保留组件外层唯一焦点框；选中色块聚焦时也只显示一个选中框。设置即时生效。

配色固定三列，默认18套呈3×6。卡片为白纸小样、实际标题/正文/引用色、五角色色条、两位编号及已选/推荐标识；没有描述段。默认青黛朱砂以推荐标识提示。卡片右上角更新/改名/删除图标在hover或focus-within显示，tooltip及aria-label保留。原稿和预览标题共用48px固定高度，工具不换行，窄预览标题栏可横向滚动。

两栏标题统一为32px圆角图标底座与双行标题：原稿使用淡蓝纸页/代码图标，主标题“原稿”、辅助标签“MARKDOWN”；公众号预览使用淡绿阅读图标，主标题“公众号预览”、辅助标签“微信阅读视图”。主标题14px/600字重、辅助标签至少11px低对比度，图标18px、文字间距清楚。两栏标题左侧同为16px边距，保留48px栏高和既有右侧操作；标题不缩小或换行，窄栏通过现有横向滚动访问工具。共用article私有scoped样式，不进入文章导出。

固定头尾各自启用、编辑/清空Markdown，即时预览和保存到localStorage。旧结尾配置保留，新开头默认空且关闭；头尾不写入正文/文章版本，不参与编号和局部标注。预览和复制顺序为开头、正文、结尾；统计包含启用的头尾。

配色初始化18套、总计1至24套，名称和角色见[排版模块](modules/typesetting.md)。原九id、已保存列表、当前文章颜色继续恢复，不自动补齐或覆盖。重置确认数量来自presets.length，确认恢复18套但不改变文章颜色；18套初始列表仍可新增6套。名称1至30字符，改名/更新/删除继续原确认流程，删除至少保留一套。标题样式共12款，两列六行，新加杂志刊头、色签标题、双线专栏和极简细线，原八款及其编号/紧贴/对齐规则保留。新配置默认杂志刊头、编号开启，旧配置不自动切换。

文字设置字号支持11至32px、步长1px，快捷档11/12/14/16/18/20/24/28/32px自动换行；默认/重置16px，1.6/1.9/2.2行距等快捷档及仅重置文字按钮沿用。默认新稿青黛朱砂/杂志刊头/暖纸引用，正文段距18px；最近色最多8个去重，本地偏好失败不阻止改色。结尾片段显式追加，追加成功同时启用结尾，不覆盖内容；往期精选提示手动去公众号编辑链接。

## 原稿、选区与阅读

2026-10-19原稿快捷格式增加“封面卡”“总结卡”两个有可见名称的按钮；无选区在当前行后插入可编辑模板，选区扩至完整行后转换。封面首行作为H1，总结已有列表保留、其他文字按行转为要点；Markdown内容和空行保留，沿用IME保护、禁用和撤销。标题样式抽屉在12款章节样式后增加卡片设置，选择星芒/菱形/无符号、填写或清空品牌落款，颜色跟随当前配色。不增加工作台顶栏或新抽屉。具体语法和失败回退见[卡片设计](markdown-cards.md)。

textarea保留IME保护、Tab和原生撤销；快捷格式修改Markdown并迁移标注。导入在原稿标题右侧；“公众号预览”带图标，标题右侧手机/电脑radio及专注。有效正文选区按revision映射；气泡五种常用色、自定义/清除，位置钳制；跨加粗/链接可选，混入代码/图片/装饰/头尾则整体拒绝。清除保留选区两侧及Markdown语义，改稿/渲染/滚动/尺寸/Escape清理临时锚点。

手机外壳默认采用390×844逻辑视口，375×812/414×896档位可切换，壳体另加边框，按空间等比缩放。仅开壳且手机模式时，在手机模型上方独立横排放置“自适应 / 原始大小”radio button及“当前缩放比例: 73%”文本，窄栏保持单行并允许该行横向滚动。这一行位于缩放模型之外，占用高度计入剩余画板空间，比例提示反映实际zoom。原始大小将zoom设为1、保持所选档位逻辑宽度，外壳高度钳制到可用视窗与所选档位高度，正文在壳内纵向滚动；窄栏可横向滚动访问完整宽度。这里的1:1指浏览器CSS像素，仍受浏览器/系统缩放影响。电脑外壳最大1100px，正文最大内容宽677px并居中留白；外壳可关，开壳内部正文滚动、关壳预览区滚动。电脑/手机都有模拟公众号元信息，位于文章根外、不标注/持久化/复制。不显示画板尺寸和复制效果提示。专注退出恢复比例。

预览标题顶部“同步滚动”按钮不显示图标，默认关闭；与“阅读外壳”、专注按钮统一使用ui-button、active背景色、aria-pressed与disabled状态，点击切换，键盘可用，无checkbox。手机/电脑与缩放radio button采用同一实心主色active背景/白色文字及hover反馈，禁用状态不响应。开启同步后，按正文块源行锚点双向映射，详见本页交互修订。workspace私有协调器requestAnimationFrame平滑追随，抑制自身写入的回环，另一侧用户滚动可接管；尊重减少动态效果。关闭、专注、恢复或卸载取消，内容/图片/模式/尺寸改变重建对齐。缩放模式和同步开关仅驻留当前页面内存，不写配置或历史。

## 反馈、输出与验证

悬浮Toast不改变布局；保存失败/暂停持续在顶栏，诊断入口保留，Toast隐藏不消除错误。终端代码块内联圆点、便签引用、主题浅底表头/固定隔行底色由公共排版服务生成，装饰不进入纯文字剪贴板。入口显式注册Radio子组件及Drawer/ColorPicker/MessageBox样式，不能仅凭构建判断运行时可用。

复制成功按钮显示绿色“已复制 ✓”持续2500ms，通过setTimeout回到“复制到公众号”，颜色过渡平滑。再次复制重启计时，修改内容使旧快照失效时立即清理计时；卸载清理计时，权限失败保留已准备内容重试。

所有交互与公众号效果待人类验收。详见[清单](../../apps/frontend/README.md)、[来源细节](../reference/source-designs/jlab-wechat-editor-ui.md)。
