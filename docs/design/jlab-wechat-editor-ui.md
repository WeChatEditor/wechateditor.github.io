# 桀士排版工作台UI与阅读交互

## 空间与视觉

沿用来源完整UI。52px单层顶栏：品牌、正文/局部颜色、设置、保存与复制；不足时仅顶栏内部横向滚动。800px最小宽度，编辑建议最小280px、预览320px，双栏比例以容器动态钳制而不覆盖用户偏好。分隔手柄无占位列、支持Pointer capture/取消/失焦与键盘。网格和flex零最小高度，原稿和预览独立滚动，标题/状态栏保留。

应用tokens归workspace私有样式；中性底色、蓝交互强调与状态色不进入文章导出，文章主题独立。底部非空白文字计数与600字/分钟估算包含启用结尾，首次示例稿按实际内容计数，用户清空后为0字/0分钟；保存状态集中顶栏。

## 抽屉与排版

无遮罩、不锁页面滚动的左覆盖Drawer位于顶栏下到状态栏上，一次一个，支持Escape/关闭/重复点击，关闭不回滚设置。配色/结尾/章节/历史最大520px并钳制工作区减40px，文字设置最大320px并钳制编辑栏；打开设置退出专注并恢复比例。设置即时生效，不增加确认/取消步骤。

配色初始化暖金、青绿、墨色、清透蓝、复古潮流、活力橙六组，总计1至9组，均可改名/更新/删除，hover或focus-within显示动作。名称弹窗预填，1至30字符，取消不写。重置确认后恢复六组，不改文章实际颜色。旧超九组完整读入，删减或重置前写入拒绝。章节九种真实卡片共用输出服务；编号独立，方括号开启[01]、关闭[ ]，结尾不编号。

文字设置14/15/16/17字号、1.6/1.9/2.2行距等快捷档及仅重置文字按钮沿用。默认新稿清透蓝/便签引用；最近色最多8个去重，本地偏好失败不阻止改色。固定结尾片段显式追加、不自动启用、不覆盖内容，往期精选提示手动去公众号编辑链接。

## 原稿、选区与阅读

textarea保留IME保护、Tab和原生撤销；快捷格式修改Markdown并迁移标注。导入在原稿标题右侧；“公众号预览”带图标，标题右侧手机/电脑radio及专注。有效正文选区按revision映射；气泡五种常用色、自定义/清除，位置钳制；跨加粗/链接可选，混入代码/图片/装饰/结尾则整体拒绝。清除保留选区两侧及Markdown语义，改稿/渲染/滚动/尺寸/Escape清理临时锚点。

手机440×956逻辑画板按空间等比缩放，电脑最大1100px；外壳可关，开壳内部正文滚动、关壳预览区滚动。电脑/手机都有模拟公众号元信息，位于文章根外、不标注/持久化/复制。不显示画板尺寸和复制效果提示。专注退出恢复比例。

## 反馈、输出与验证

悬浮Toast不改变布局；保存失败/暂停持续在顶栏，诊断入口保留，Toast隐藏不消除错误。终端代码块内联圆点、便签引用、表头/隔行底色由公共排版服务生成，装饰不进入纯文字剪贴板。入口显式注册Radio子组件及Drawer/ColorPicker/MessageBox样式，不能仅凭构建判断运行时可用。

所有交互与公众号效果待人类验收。详见[清单](../../apps/frontend/README.md)、[来源细节](../reference/source-designs/jlab-wechat-editor-ui.md)。
