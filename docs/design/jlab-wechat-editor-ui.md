# 桀士排版工作台UI与阅读交互

## 网站图标

浏览器图标使用蓝白配色的纸页与字母 J 图形，沿用工作台主色 #2563EB。图形保持粗线条和少量排版横线，适合小尺寸标签页。生成原图与提示词保存在 docs/reference/brand/；应用 public/ 保存多尺寸 favicon.ico、32px/192px PNG 和 180px Apple 图标，HTML 使用相对路径，兼容 GitHub Pages 仓库子路径。图标不影响文章导出、界面标题或存储协议。生成素材需人工确认视觉；允许的验证为资源尺寸、ICO 结构、生产产物及静态工程检查。

## 空间与视觉

沿用来源完整UI。52px单层顶栏：品牌、正文/局部颜色、设置、保存与复制；不足时仅顶栏内部横向滚动。800px最小宽度，编辑建议最小280px、预览320px，双栏比例以容器动态钳制而不覆盖用户偏好。分隔手柄无占位列、支持Pointer capture/取消/失焦与键盘。网格和flex零最小高度，原稿和预览独立滚动，标题/状态栏保留。

应用tokens归workspace私有样式；中性底色、蓝交互强调与状态色不进入文章导出，文章主题独立。底部非空白文字计数与600字/分钟估算包含启用头尾，首次示例稿按实际内容计数；正文及启用头尾为空时为0字/0分钟，保存状态集中顶栏。

共用ui-button的active背景与主色文字在hover时保留，避免已选状态被普通hover底色覆盖；预览两组radio button使用实心主色背景、白色文字及主色边框，hover时保留选中态。

## 抽屉与排版

无遮罩、不锁页面滚动的左覆盖Drawer位于顶栏下到状态栏上，一次一个，支持Escape/关闭/重复点击，关闭不回滚设置。配色最大640px，固定头尾/标题样式/历史最大520px，均钳制工作区减40px；文字设置最大320px并钳制编辑栏。工具依次文字设置、标题样式、配色、固定头尾；正文色/局部字色只显示色点和名称。所有调色面板按钮“清除/确定”，输入框保留组件外层唯一焦点框；选中色块聚焦时也只显示一个选中框。设置即时生效。

配色固定三列，九项呈3×3；删除“看看标题、正文与引用如何相处。”描述文字。卡片右上角更新/改名/删除图标在hover或focus-within显示，tooltip及aria-label说明动作。原稿和预览标题共用48px固定高度，工具不换行，窄预览标题栏可横向滚动。

固定头尾各自启用、编辑/清空Markdown，即时预览和保存到localStorage。旧结尾配置保留，新开头默认空且关闭；头尾不写入正文/文章版本，不参与编号和局部标注。预览和复制顺序为开头、正文、结尾；统计包含启用的头尾。

配色初始化暖金、青绿、墨色、清透蓝、复古潮流、活力橙六组，总计1至9组，均可改名/更新/删除，hover或focus-within显示动作。名称弹窗预填，1至30字符，取消不写。重置确认后恢复六组，不改文章实际颜色。旧超九组完整读入，删减或重置前写入拒绝。章节八种真实卡片共用输出服务；编号独立，序号和完整标题置于方括号/双圆/点阵内部，斜线位于末尾，竖线位于前侧。紧贴标题开关默认开启（两种下划线除外）；关闭时装饰在行边。左/中/右对齐默认左，仅控制章节标题。开头和结尾不编号。

文字设置14/15/16/17字号、1.6/1.9/2.2行距等快捷档及仅重置文字按钮沿用。默认新稿清透蓝/便签引用；最近色最多8个去重，本地偏好失败不阻止改色。结尾片段显式追加，追加成功同时启用结尾，不覆盖内容；往期精选提示手动去公众号编辑链接。

## 原稿、选区与阅读

textarea保留IME保护、Tab和原生撤销；快捷格式修改Markdown并迁移标注。导入在原稿标题右侧；“公众号预览”带图标，标题右侧手机/电脑radio及专注。有效正文选区按revision映射；气泡五种常用色、自定义/清除，位置钳制；跨加粗/链接可选，混入代码/图片/装饰/头尾则整体拒绝。清除保留选区两侧及Markdown语义，改稿/渲染/滚动/尺寸/Escape清理临时锚点。

手机外壳默认以440×956逻辑画板按空间等比缩放。仅开壳且手机模式时，在手机模型上方独立横排放置“自适应屏幕 / 原始比例”radio button及“当前缩放比例: 73%”文本，窄栏保持单行并允许该行横向滚动。这一行位于缩放模型之外，占用高度计入剩余画板空间，比例提示反映实际zoom。原始比例将zoom设为1、保持440px逻辑宽度，外壳高度钳制到可用视窗（最大956px），正文在壳内纵向滚动；窄栏可横向滚动访问完整宽度。这里的1:1指浏览器CSS像素，仍受浏览器/系统缩放影响。电脑最大1100px；外壳可关，开壳内部正文滚动、关壳预览区滚动。电脑/手机都有模拟公众号元信息，位于文章根外、不标注/持久化/复制。不显示画板尺寸和复制效果提示。专注退出恢复比例。

预览标题顶部“同步滚动”按钮不显示图标，默认关闭；与“阅读外壳”、专注按钮统一使用ui-button、active背景色、aria-pressed与disabled状态，点击切换，键盘可用，无checkbox。手机/电脑与缩放radio button采用同一实心主色active背景/白色文字及hover反馈，禁用状态不响应。开启同步后，以scrollTop/(scrollHeight-clientHeight)将原稿textarea与当前预览滚动容器双向联动，比例钳制0至1，无滚动范围视为0。workspace私有协调器用requestAnimationFrame合并并平滑追随，识别自身写入的滚动位置以避免回环；用户从另一侧滚动可接管。尊重减少动态效果设置。关闭、专注、恢复或卸载时取消追随；开壳/模式/尺寸改变后重新按原稿比例对齐。按总高度比例近似匹配，固定头尾、图片和Markdown排版会使具体段落错位。缩放模式和同步开关仅驻留当前页面内存，不写配置或历史。

## 反馈、输出与验证

悬浮Toast不改变布局；保存失败/暂停持续在顶栏，诊断入口保留，Toast隐藏不消除错误。终端代码块内联圆点、便签引用、表头/隔行底色由公共排版服务生成，装饰不进入纯文字剪贴板。入口显式注册Radio子组件及Drawer/ColorPicker/MessageBox样式，不能仅凭构建判断运行时可用。

复制成功按钮显示绿色“已复制 ✓”持续2500ms，通过setTimeout回到“复制到公众号”，颜色过渡平滑。再次复制重启计时，修改内容使旧快照失效时立即清理计时；卸载清理计时，权限失败保留已准备内容重试。

所有交互与公众号效果待人类验收。详见[清单](../../apps/frontend/README.md)、[来源细节](../reference/source-designs/jlab-wechat-editor-ui.md)。
