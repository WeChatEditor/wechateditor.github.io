# 桀士排版·公众号助手

## 产品和范围

桀士排版，英文JLab WeChat Editor，是独立仓库apps/frontend中的Vue/Pinia/Element Plus纯前端桌面单页。无需Router、认证、后端或HTTP业务契约。浏览器标题“桀士排版·公众号助手｜微信公众号 Markdown 排版工具”，顶栏继续“桀士排版”/“公众号助手”。完整保留源产品界面与能力，首次无本地草稿时加载内置新手示例稿，已有草稿（包括空稿）优先恢复；默认九组配色，排版与结尾启停规则沿用。

2026-10-16新增[搜索发现](search-discovery.md)：编辑器根入口保留，独立静态产品介绍、Markdown转公众号教程、插件安装与隐私说明通过工作台状态栏普通链接在新标签打开，不加载编辑器或读取草稿。目录HTML、canonical、分享元信息、JSON-LD、robots和sitemap由既有Vite静态发布路径交付；公开说明不增加编辑器业务能力、Router或后端。此前排除的交互教程模块仍不在范围。

## 首次示例稿

内置标题保留“把想法，排成好文章”，正文扩展为可直接编辑的长篇示例，展示标题、强调、引用、列表、表格、分隔线、行内代码，以及16种自然语言文字和30种编程、标记、配置与命令代码块。操作说明采用现行按钮名称，覆盖配色、标题样式、阅读预览、固定头尾、自动保存、主动历史版本与复制到公众号。语言标签只示范代码块写法与内容展示，不承诺语法高亮或运行代码；不增加远程图片或其他加载依赖。默认内容仍由app.config.ts的exampleMarkdown提供，不增加独立教程入口、存储字段或自动覆盖已有草稿。实施与人工验收见[计划](../plans/active/2026-10-14-expanded-example-draft.md)。

## 工作流

2026-10-12已实现可选的[Chrome轻量传稿插件](wechat-transfer-extension.md)及Web一键发送：自动保存成功后同步当前文字排版供插件复制，手动点击发送才打开后台尝试独立新建插入；未完成时可从插件面板复制最新排版或标题，不需返回编辑器。插件0.1.5以独立可复制快照隔离原发送任务，24小时到期或下一次成功同步/发送替换复制内容；默认第一个可用公众号、紧凑导航、logo和账号右侧刷新，不再确认标题或插件任务，不检测发送状态。实际Chrome同步、公众号及富文本粘贴仍待人类验收，不能将构建当作功能/插入/保存证明。生产Web由维护者确认为https://wechateditor.github.io/。用户检查后手动保存；含图片文章提示既有编辑器复制流程。Web保持文章、配置和主动历史的数据所有者，不迁移到插件、不引入官方HTTP草稿API或服务端。

左Markdown原稿 → article受控解析/序列化局部标注 → typesetting公共规则与ending片段 → article预览 → assets准备 → wechat-export清洗/内联 → HTML和纯文字剪贴板。workspace编排命令并拥有草稿仓储；App/main只组装。原始HTML禁用并显示为文本，不将输入直接插入预览。

保留UTF-8单个.md/.txt导入（2MB/50万字符）、Markdown快捷格式/IME/撤销、实时预览、正文/局部颜色、八种标题样式/独立编号、字号/间距/字体、九组默认/总计1至9配色、固定头尾、双栏比例/专注/阅读宽度、历史和保存诊断。数学、Mermaid、复杂SVG、插图和下载、文章包、IP/提色/教程、账号/云同步/AI排版不在范围。

九组默认配色统一重设计，覆盖简洁朴素、自然、科技、复古和撞色风格，名称与五种颜色角色见[排版模块](modules/typesetting.md)。新配置默认澄空科技；已有配色列表及文章颜色保留，确认“重置所有配色”才恢复新版九组。静态工程验证与人工验收见[配色计划](../plans/active/2026-10-15-nine-default-palettes.md)。

## 布局和存储

桌面最小宽度800px，52px单层顶栏，小于800px页面横向滚动，不做手机工作台。文字设置最大320px、配色640px三列、标题样式/固定头尾/历史520px左覆盖抽屉。原稿和预览标题固定48px。左右默认独立滚动，可开启按标题/段落等正文块锚点双向同步；无占位分隔线与键盘操作。仅手机外壳启用时，在模型上方横排“自适应 / 原始大小”radio button与“当前缩放比例: N%”，原始大小保持1:1 CSS像素/壳内滚动。同步与阅读外壳均用active背景按钮；阅读手机/电脑外壳属于预览模拟，永不进入文章、标注或复制。底部统计包含启用头尾，按600字/分钟向上取整。

配置与头尾localStorage即时覆盖；旧结尾完整保留，缺失开头补空且关闭，原稿上下显示启用头尾的浅灰只读块。正文/标注/Blob IndexedDB current 450ms串行防抖；用户主动新增时间戳文章版本，恢复不回滚配置/头尾。未知格式/损坏暂停对应写入并保留原记录；多标签冲突锁定整个页面，以Modal提示自动保存暂停并确认关闭标签页。手机视口提供375/390/414px内存档位，CSS最小字号11px。浏览器存储按origin隔离，源数据不搬迁。

## 输出和失败模式

本地旧素材使用稳定asset:id与Blob；HTTPS图片可预览，远程fetch/CORS失败阻止复制。PNG/JPEG/WebP等比限制1440×2400，WebP转PNG、保留透明；GIF保留动画，超限拒绝。相对图片不扫描目录。站外链接输出可见URL。默认公众号字体省略font-family，显式字体选择共用于预览与导出但不保证设备安装。

受控DOM和DOMPurify清洗保留，UI外壳/临时诊断不参与输出。复制快照过期不可用，权限失败可重试已准备内容；成功显示绿色“已复制 ✓”2500ms后复位。主动追加结尾片段同时启用结尾。保存成功以事务完成为准。候选输出profile不承诺微信保真。
