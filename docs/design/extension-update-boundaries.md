# 插件转发职责与升级边界

依据维护者本轮指令与[ADR](../decisions/ADR-20261021-extension-opaque-html-relay.md)，插件只接收可信Web的快照、保存、复制及通过官方接口写入，不解释正文HTML/CSS格式。

## 职责与数据流

公共传输入口wechat-transfer.schema.ts移除parse5和内容规则依赖。新增独立公共入口wechat-transfer.content.ts（包subpath为/content），提供Web格式、媒体和标题规则；模块名与依赖方向保持，注册此公共文件。Web预览/导出/提交继续执行原有规则。

插件接收及popup复制不再调用validateTextHtml；页面适配器不再检查正文标签数量或拒绝读回媒体。来源、Schema、2MiB、digest、TTL/去重、账号、新建空文章、用户活动和写入读回文字保护保留。标题64字上限只在Web；插件不设置兜底64，仅读取实际控件限制。profile只验证有界字符串，不解释版本。纯文本读回不能证明图片或排版保真，当前Web含图仍阻断自动传稿。

PING的capabilities为可选有界字符串数组，0.1.15声明html-relay@1；缺失表示旧插件仍可能限制格式。Web按该稳定能力检测，不比较发布版本；能力名不随主题、样式或内容profile变化。旧网页可能无法识别新PING字段，此次需同时部署Web和发布插件，未来正常排版更新无需重复发布插件。

## 升级耦合审计

| 位置/功能                                       | 何种变化影响升级                   | 本轮处理                               |
| ----------------------------------------------- | ---------------------------------- | -------------------------------------- |
| HTML/CSS/媒体/官方建议                          | 网页新增样式或规则                 | 插件删除，Web独立                      |
| 固定profile/标题64/标签计数                     | 内容profile、标题规则或DOM输出变化 | 改不透明标签、Web标题及文字读回        |
| 网页按插件版本同步                              | 每次排版更新                       | 改稳定能力握手，仅首次迁移升级         |
| 消息kind、严格字段、protocolVersion、digest顺序 | 新增操作、字段或摘要算法           | 保留明确协议；此类变化仍协调升级       |
| payload/仓储schemaVersion、TTL、2MiB和去重      | 原生缓存、尺寸/生命周期能力        | 保留；改变时需升级插件                 |
| 公众号菜单/账号/标题选择器和官方JSAPI           | 微信后台页面或接口改变             | 保留页面适配，仍可能升级插件           |
| 顶层文档、新子tab与不同documentId               | 后台改为SPA/iframe/同tab新建       | 保留防覆盖边界，适配需升级             |
| host/externally_connectable、站点ID、图标匹配   | 新域名、路径、扩展身份或权限       | 保留精确来源；改变需发布manifest/代码  |
| Chrome API、popup、content浮层与图片上传        | 插件界面或浏览器原生能力变化       | 插件自身能力仍独立发布；不远程执行代码 |

## 失败与验证

缺少能力明确提示更新，不将旧格式校验版误认为可转发。未知消息、非法字段、超限、来源/摘要错误仍拒绝；不会因为HTML/CSS规则变化而拒绝。契约检查覆盖未来profile与HTML的传输接受、Web仍拦危险内容和能力判定；打包检查禁止内容规则/parse5/entities进入任何插件bundle。前端功能、实际插入与保存由人类验收。
