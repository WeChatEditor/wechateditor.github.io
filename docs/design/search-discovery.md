# 网站与插件搜索发现

## 目标与范围

维护者授权按SEO建议优化整个项目。生产来源为https://wechateditor.github.io/。根路径继续打开既有编辑器；品牌保留“桀士排版·公众号助手”，浏览器标题增加微信公众号Markdown排版用途。新增公开产品、教程、插件安装和隐私说明，帮助搜索用户判断与使用产品。不移动编辑器，不迁移origin或本地数据，不增加账号、追踪、后端、Router或依赖。

## 静态内容和发布边界

公开页面作为apps/frontend/public中的静态HTML及共用CSS，Vite原样复制至dist，GitHub Pages直接按目录index.html提供服务。它们是产品说明资产，不新增业务模块或模块依赖。每页提供独立标题、摘要、绝对canonical、Open Graph/Twitter元信息、一个主标题、语义导航和完整正文；页面可在禁用JavaScript时阅读。根HTML包含真实加载说明和公开页面链接，挂载后由既有编辑器替换；工作台状态栏保留通往公开页面的普通链接，在新标签打开，避免离开正在写作的草稿。

产品介绍、Markdown转公众号教程、插件安装和隐私分别位于/about/、/guides/markdown-to-wechat/、/extension/、/privacy/。根路径和四页进入sitemap.xml，robots.txt指向生产站点地图。canonical逐页自引用，不把所有页面指向根路径；不添加meta keywords、虚构评价或富结果承诺。根页使用WebSite/WebApplication结构化数据，说明页使用WebPage和BreadcrumbList。分享图片沿用现有192px品牌图标，使用summary卡片。404页明确noindex，不进入站点地图。

2026-10-19产品介绍与教程同步18套默认/24套上限和12款标题；静态示意采用青黛朱砂，色票取现行默认数据。示意仍与实际工作台/公众号验收分开。

## 免费与开源说明

2026-10-21维护者要求增加开源、免费宣传，帮助用户选择。产品介绍首屏突出“免费使用、MIT开源、无需注册”，在功能介绍前增加可直达的open-source区块，解释免费排版功能、浏览器本地草稿与源码入口，并提供GitHub源码和仓库LICENSE链接。FAQ说明适用的Markdown写作场景、插件可选及跨设备云同步边界，帮助用户判断用途。宣传依据为现有MIT许可证和纯前端实现；只描述当前免费使用，不承诺永久免费、不虚构付费对比、用户数量或平台背书。

工作台品牌旁增加“免费 · 开源”普通链接，在新标签打开./about/#open-source；底部原GitHub链接改为“开源代码 ↗”。根HTML加载正文、搜索与分享摘要、WebApplication描述及license字段同步，根README同步免费/开源定位和现行配色/标题数量。插件说明首屏补充免费、开源与网页可独立使用的说明，链接同一产品区块。根页和产品页sitemap日期更新。沿用现有静态页面与模块依赖，工作台不增加弹窗、存储或新模块，说明页复用卡片网格和响应式样式。

验证仅执行工程门禁及构建HTML、JSON-LD、本地链接与锚点的静态核对；工作台窄屏布局、文字阅读和链接体验待人工验收。见[实施计划](../plans/active/2026-10-21-free-open-source-messaging.md)。

## 插件与商店

插件保留名称、权限、来源与传稿行为，0.1.12时将manifest摘要改为用户场景，当前0.1.13保留并增加站点图标指示，homepage_url指向公开插件页。2026-10-21维护者确认商店已审核发布，正式ID为neeljhohndegbhaaaclmcdeenlebhicj；公开插件页首屏和安装步骤直接链接Chrome应用商店，不再引导普通用户下载GitHub工件或打开开发者模式。页面说明安装/更新后刷新和重新检测、权限排查及旧手动包迁移，开发安装留在指南。插件页摘要与sitemap lastmod同步，详情链接与共享契约和身份文件由打包检查核对。发布状态依据维护者确认，真实安装/连接和公众号功能待人工验收。

自动插入只描述为辅助尝试，用户检查后手动保存，含图文章使用Web原复制流程。隐私说明依据现行localStorage/IndexedDB、插件chrome.storage.local、账号识别和24小时快照清理机制，说明外链图片请求、静态托管访问日志及浏览器清理风险，不声称完全离线或从不发生网络请求。

2026-10-19隐私页补充插件对允许站点当前URL的本机读取、公众号完整导航链接可能包含会话参数、检测真实页面操作以中止自动写入的用途；区分检测操作发生与记录按键/鼠标轨迹/输入内容，区分当前URL匹配与浏览历史档案。数据仅用于文字传稿、复制、站点提示与人工编辑保护，声明不出售、不用于广告画像、无关用途或信贷，并说明公众号为用户指定的接收平台。保留24小时到期后按读取/命令清理和账号偏好独立保留的实际机制；日期和侧边目录同步。商店参考文案按事实解释数据类别和认证信息判断，不以无后端等同于不处理数据。对应[实施计划](../plans/active/2026-10-19-extension-privacy-disclosure.md)及[协作记录](../ai-logs/docs/2026/10/2026-10-19-extension-privacy-disclosure.md)。本次不改变静态架构、插件行为或权限，也不代表已部署或已通过商店审核。

## 数据流、失败和验证

搜索/官网链接 → 静态说明页 → 编辑器或插件安装帮助；静态说明页不加载编辑器脚本、不访问草稿或锁。构建仅复制静态资产。部署遗漏public文件、canonical域名漂移、无链接入口、商店未公开或未提交搜索平台，分别记录，不能以本地构建证明线上收录。

按仓库执行格式、Lint、类型、构建、模块/文档/归档检查、治理与契约测试、插件打包检查。只静态核对构建HTML、元数据、JSON-LD、站点地图与本地链接，不创建或运行前端自动化测试。产品页面布局、链接体验、公众号传稿由人类验收。Search Console/Bing/百度所有权、商店后台和搜索表现需维护者账号，交付可操作指南，不伪造验证token或提交结果。
