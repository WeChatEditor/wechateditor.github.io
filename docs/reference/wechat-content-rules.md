# 微信内容规范核对记录

0.1.15起本记录仅约束Web输出。插件不做格式检查，职责与升级边界以[纯转发设计](../design/extension-update-boundaries.md)为准。

核对日期：2026-10-21。依据维护者指定的[官方页面](https://developers.weixin.qq.com/doc/service/guide/product/plugin_spec.html#_4-1-2)，及页面明确指定为权威的[官方规则文件](https://github.com/wechatjs/verify-article-structure-spec/blob/ab0a16a0ae07cfc128c7f3fc2d061cf9c7dbff78/verify_article_structure.md)。文件最后变更提交为ab0a16a0ae07cfc128c7f3fc2d061cf9c7dbff78，日期2026-10-19；网页与仓库内容不完全同步。Jina读取失败后直接读取官方HTML，不使用第三方转载代替依据。

| 规则                              | 项目处理                                  | 证据边界                                       |
| --------------------------------- | ----------------------------------------- | ---------------------------------------------- |
| 1.1 / 1.7 图片与SVG交互           | 文字传稿整篇拒绝媒体，富文本不生成SVG     | 不实现SVG交互检查                              |
| 1.2 光标；1.6 对齐；1.5.1 零高度  | 静态确认时阻断，提示规则与节点            | 不把装饰误作文字                               |
| 1.3 / 1.4 / 1.5.2 行高、宽高      | 风险提示                                  | 真实布局、跨屏与滚动人工核验                   |
| 1.8 pre                           | 保留pre-wrap代码块，提示缺少换行/滚动保护 | 权威文件允许可换行或可横向滚动的代码           |
| 2.1 嵌套                          | 根深度0，从15层检查简单冗余               | 页面仍写10层，按指定权威文件，不设通用深度上限 |
| 2.2 / 2.3 内部节点                | 不生成leaf/nodeleaf；传稿属性集合拒绝     | 不开放平台专用组件                             |
| 3 字体；4.5.2 important           | 建议提示，不伪称平台禁用                  | 设备字体与深色转换人工核验                     |
| 4.1.2 / 4.1.3 渐变                | 总结卡改纯色；有文字时提示，无文字时允许  | 不把gradient归为媒体URL                        |
| 4.2.2 定位顺序                    | 定位/变形文字提示                         | 是否破坏视觉顺序需真实布局                     |
| 4.1.1 / 4.3 / 4.4 深色、图片与SVG | 沿用颜色回退和图片提示                    | 不声称实现微信Dark Mode或图像识别              |
| 4.5.1 / 4.6 豁免                  | 不生成豁免属性                            | 不用标记隐藏真实问题                           |

box-shadow、list-style、border-image:none未被官方列为禁用属性。项目仅扩展已生成且无需资源的受控集合；继续禁止URL、CSS转义、变量、脚本及未知属性。静态校验成功不等于公众号接收、保存或客户端阅读已通过。
