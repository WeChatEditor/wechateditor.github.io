## 名称

桀士排版·公众号助手

## 简短摘要

配合桀士排版同步微信公众号文字排版，支持复制正文与标题，辅助新建文章并插入内容，由你检查后手动保存。

## 详细介绍

桀士排版·公众号助手是一款配合桀士排版网页使用的Chrome文字传稿插件。你可以在网页用Markdown写作和调整样式，将最新文字排版同步到插件，再复制正文与标题到微信公众号后台；也可以点击“发送到公众号”，由插件辅助新建文章并尝试插入内容。

主要功能：

- 文字排版同步：网页本地保存成功后同步当前文字排版，插件面板可随时打开使用。
- 复制正文与标题：分别复制带排版的文字正文或文章标题，便于粘贴到对应编辑区域。
- 辅助公众号传稿：主动发送时尝试打开后台、新建独立空文章并插入本次文字快照。
- 手动复制退路：自动插入未完成时，可从插件面板复制已经同步的文字内容。
- 站点图标提示：当前标签为桀士排版或公众号后台时图标呈蓝色，其他网页灰色；灰色仍可打开插件面板。

使用方式：

1. 在桀士排版网页完成Markdown原稿和排版。
2. 登录微信公众号后台，按需在插件内选择目标账号。
3. 在插件面板复制正文/标题，或在网页点击“发送到公众号”尝试自动插入。
4. 在公众号后台核对内容与排版，补全封面、摘要等信息，再手动保存。

使用前请了解：

- 插件需要桌面Chrome120及以上，配合桀士排版网页使用，不提供独立文章编辑器。
- 当前传稿范围为文字排版，含图片文章请使用网页的“复制到公众号”流程。
- 公众号后台变化、登录状态、账号识别或编辑器内容可能导致自动插入停止，不保证每次成功，不会自动发布。
- 原稿和文章版本保存在网页当前浏览器，插件保留短期文字快照和任务信息，没有云端草稿同步。
- 文字快照采用24小时有效期，到期后在插件读取或处理命令时清理，下次成功同步或发送也会替换可复制内容。

权限用途：

- storage：本地保存文字快照、任务、回执和账号选择偏好。
- scripting：在公众号后台执行账号识别、能力检查与用户主动发起的文章插入。
- 网站访问权限：仅微信公众号后台和桀士排版生产网站，用于连接、识别和传稿。

## 隐私申报事实核对

2026-10-19依据当前0.1.13实现补充以下事实，公开说明对应apps/frontend/public/privacy/index.html。此处是表单分类建议，不表示已读取后台当前问卷、已代为勾选或通过审核；以实际上传版本和字段定义核对。

| 数据类别      | 当前实现与申报依据                                                                                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 网站内容      | 标题、正文文字和排版HTML进入插件；公众号编辑页内容用于判空及写入核对，应披露。                                                                                                   |
| 个人身份信息  | 读取公众号显示名称以核对目标，所选名称作为本地偏好保留；按账号/用户名信息披露。                                                                                                  |
| 网络/浏览记录 | 现有站点权限允许读取对应标签当前URL，用于站点图标、目标核对与导航；不读取浏览历史数据库、不建立历史档案，但当前URL处理仍需披露。                                                 |
| 用户活动      | 公众号页面监听是否发生真实指针、键盘或输入操作以中止自动写入，仅报告发生操作，不记录按键内容、鼠标轨迹或输入过程；按实际事件处理披露。                                           |
| 身份验证信息  | 当前实现复用已打开公众号后台的完整URL，其中可能包含平台会话参数；建议保守披露这一情况，不应只因未调用Cookie接口就承诺完全不处理认证信息。具体分类需按实际URL内容和后台定义核对。 |

健康、财务付款、个人通讯与定位信息不是当前功能专门收集的类别，不因文章可以写任意主题就将所有类别一律勾选。当前实现不出售数据、不将数据用于无关用途或广告画像、不用于信用评估/贷款；向公众号插入属于用户主动指定的传稿功能，不能笼统声明所有数据从不离开浏览器。

本地快照/任务/回执采用24小时有效期，到期后在读取或命令处理中清理，账号选择偏好独立保留。扩展脚本及依赖随包，不下载执行远程扩展脚本。公开政策、单一用途、权限理由和数据勾选需描述同一事实；更新政策源码和本地构建不等于线上已更新，部署后再检查https://wechateditor.github.io/privacy/。
