# 编辑式配色与标题参考研究

2026-10-19通过维护者指定的Chrome标签页读取，以下为当次页面观察，不代表持续在线状态。

## md2wechat

[在线编辑器](https://www.md2wechat.cn/editor)设置展示48个主题，含常用6、精选10和模板32。精选包括NYT、GitHub、少数派、薄荷、日落、水墨、薰衣草、咖啡和Bauhaus。当前默认样张以暖白纸、棕红强调、编号方框、浅底摘录和细线组织阅读，主视觉有刊头/眉题/主标题/副标题的层级。可借鉴的原则是同一强调色贯穿标题与引用、装饰服务信息结构；不引入其专用容器语法。

## 花生公众号排版器

[在线编辑器](https://editor.huasheng.ai/)可见20个风格入口，包括金融时报、Claude、深度阅读、Apple极简、原研哉、编辑部和建筑风格。优雅简约使用衬线、居中、较多留白和浅灰细线；切换金融时报后，实际h1为38px Georgia/serif、黑字、4px深莓红底线，文章为浅桃纸底，二级标题和装饰采用莓红。观察后恢复原选优雅简约，未修改文章或历史。

## 桀士排版的实现选择

保留白底文章和可自由搭配的标题/配色。18套默认颜色采用五角色体系：耐读正文、深色标题、醒目强调、低一级引用、浅纸底。默认青黛朱砂将冷色标题与暖色强调配对；新增四种以线条、色签、独立编号组织的标题。卡片显示真实颜色与小样，不复刻参考站品牌或源码。

首屏以主标题、简短导语、章节、加粗/行内代码、浅底引用展示全部颜色角色；后续保留完整Markdown、多语言与代码阅读材料。纯文本原稿不引入HTML、图片或特殊解析协议。静态颜色计算与工程检查不替代公众号实际粘贴和人类视觉验收。
