# 桀士排版工作台 UI 与阅读交互

2026-10-07第二轮人工验收调整：配色卡片操作行在hover或键盘focus-within时显示，包含更新颜色、修改名称、删除；名称通过弹窗预填编辑，限制30字符且不能为空，取消不写配置。导入按钮靠原稿标题栏右侧；预览标题为带左侧图标的“公众号预览”。章节、历史版本与配色、结尾抽屉统一最大520px，钳制工作区宽度减40px；文字设置仍最大320px并钳制编辑栏宽度。方括号样式开启编号时为`[01] 章节标题`，关闭为`[ ] 章节标题`，共用于卡片、正文和复制。画板尺寸提示及底部复制效果提示移除，外壳仍与文章根分离。人工交互与公众号效果待维护者复验。

维护者批准 V2 设计并要求实施完整修改；电脑预览也必须有阅读外壳。应用仍为独立纯前端桌面工具。正文、配置、本地保存、历史版本与受控导出沿用[独立应用设计](jlab-wechat-editor.md)和[存储设计](jlab-wechat-editor-storage.md)。

## 视觉和空间

2026-10-06品牌与按钮调整：对外名称统一为“桀士排版·公众号助手”，顶栏保留标题“桀士排版”和副标题“公众号助手”，移除英文应用名与底部重复品牌。主要操作采用语义明确的内联SVG线性图标并保留文字，图标隐藏于无障碍树，不新增依赖。手机外壳使用浅灰细边框与轻阴影，保留圆角、灵动岛和原有滚动缩放。内部包名、路径及存储命名空间保持兼容。

配色数量最终规则：默认和用户保存配色共用一个列表，总计1至9组，六组默认配色仅供初始化，均可改名、删除；修改颜色后可以保存当前配色。“重置所有配色”确认后恢复默认六组并保留当前文章实际颜色。旧版超过九组的列表保留读入，需用户删减或重置后才写回，不静默截断。

2026-10-06人工验收调整：章节序号由独立开关控制，章节样式仅控制标题装饰；编号按正文章节顺序生成，固定结尾不编号。初始配色为暖金、青绿、墨色、清透蓝、复古潮流、活力橙，可改名和删除；所有配色共用一个列表，总计1至9组，存入现有配置并校验。配色、结尾、章节样式与历史版本抽屉最大520px，允许覆盖部分预览；文字设置抽屉保持320px。色板横向换行，颜色值输入使用单层焦点边框。阅读外壳完整显示，正文在壳内滚动；无外壳时整个预览滚动。手机采用Pro Max比例、圆角金属边框、灵动岛和底部手势条；电脑参考维护者截图的浅灰工具栏与白色公众号阅读页。预计阅读按600字/分钟。往期精选使用纯文本“精选介绍 【手动去公众号编辑往期链接】”。

workspace 私有样式定义应用背景、表面、中性文字、边框、蓝色交互强调、状态色、圆角和阴影 tokens；文章配色独立，换主题不改变操作控件。顶栏52px、控件13px、辅助12px、最低11px。四区依次为品牌、快捷颜色、设置、保存与复制；宽度不足时仅顶栏内部横向滚动。保留800px桌面最小宽度、双栏比例、无占位分隔手柄和独立滚动。

左侧非模态覆盖抽屉从顶栏下方至状态栏上方；配色、结尾、章节样式和历史版本最大520px，钳制到工作区宽度减40px，可覆盖部分预览；文字设置抽屉最大320px并钳制到编辑栏宽度。打开设置退出专注、恢复原比例。九种章节卡片调用typesetting公共预览服务复用文章装饰规则；初始化六组、总计1至9组的可编辑配色卡片展示标题、正文与引用。文字设置保留原范围，增加14/15/16/17字号、1.6/1.9/2.2行距及仅重置文字参数的按钮。

## 颜色和选区

typesetting公共颜色组件包裹Element Plus ColorPicker，展示当前色、推荐色和最近使用色；最多8个去重色以独立应用localStorage键保存，读取/写入失败只影响推荐记录，不阻止文章改色。article只依赖该公开呈现入口，无反向依赖，无跨浏览器吸管承诺。

article-preview 捕获有效正文选区，通过现有来源映射和revision发出TextSelection。鼠标/键盘选区完成后显示气泡：五个常用色、自定义、清除颜色。位置优先上方8px，顶部不足翻至下方，横向钳制到预览容器。代码、图片、装饰、固定结尾和模拟元信息不进入选区。混合无效选区整体拒绝。

弹出颜色面板前保存可序列化选区，鼠标点击气泡保留锚点；颜色命令由workspace编排，article公开清除服务保留未选中片段，不删除加粗/链接语义。改稿、重渲染、滚动、尺寸变化、Escape关闭气泡；无有效选择时顶部局部字色说明操作方式。气泡不提供第二套加粗标注，加粗由Markdown快捷格式操作。

## 编辑和阅读

Markdown原稿保留textarea、IME保护和Tab行为，增加标题、加粗、斜体、引用、代码、有序/无序列表快捷格式；变更通过原有事件和标注迁移命令。使用原生文本编辑命令保留支持浏览器的撤销链，不引入编辑器依赖。导入仍在原稿标题右侧。

手机440×956px逻辑画板与电脑最大1100px画板都提供可关闭的阅读外壳。手机按可用空间等比缩放，电脑填满可用高度，文章在壳内滚动；关闭外壳后在预览区滚动。手机有模拟状态栏和微信导航；电脑有桌面阅读导航。两者都有模拟公众号/原创说明，不虚构作者、地区或发布时间。文章标题仍由原文唯一产生；模拟元信息在article根外，永不进入复制。空间不足时自适应，不展示画板宽度或复制效果提示。外壳开关为临时UI状态，不改变草稿或导出。专注模式退出恢复原比例。

## 稳定反馈与输出

临时消息使用悬浮Toast，不参与工作区布局；诊断入口保留图片/导出/失效标注明细。保存失败/暂停持续显示在顶栏，允许原有重试；不会因Toast消失而隐藏。失效标注提供显式清除，不删除有效标注。

输出共用typesetting规则：浅色终端代码块含三个纯内联装饰圆点、引用便签底色、表头底色与隔行底色。装饰标记在纯文本导出前移除；不依赖伪元素/绝对定位，不加入应用或阅读外壳。最终DOMPurify受控清洗仍执行，不能承诺微信保真。固定结尾提供名片、关注提示、往期精选手动链接提示片段，只有用户点击追加才写入结尾，不替换既有内容或自动启用；沿用现有localStorage保存；往期精选不生成Markdown链接。
