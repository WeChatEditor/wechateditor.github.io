# 轻量传稿插件安装与验收

当前版本0.1.3，协议2，Chrome桌面最低120。支持维护者提供的首页weui-desktop_name及其他页面acount_box-nickname。完整公众号流程仍待人类验收；构建和接收应答不证明插入或保存成功。

## 安装与更新

1. 执行pnpm package:extension，得到apps/extension/dist/production及apps/extension/dist/jlab-wechat-transfer-0.1.3.zip。
2. Chrome打开chrome://extensions，打开开发者模式，加载production目录或解压后的ZIP目录。插件稳定ID与extension.identity.json一致，可固定到工具栏。
3. 已安装旧版时在扩展管理页重新加载，再刷新Web和公众号标签；Web与插件必须一起更新到协议2。旧快照不会自动执行，从编辑器重新发送当前内容。
4. 生产Web为[组织站点](https://wechateditor.github.io/)。本轮仅本地修改/打包，线上更新需另行推送部署。
5. 本地验收运行pnpm dev:frontend、pnpm build:extension:dev，加载apps/extension/dist/development，访问http://127.0.0.1:5175/（preview为4175）。开发/生产包相同ID，只安装一份，插件不搬迁不同origin的Web数据。

权限仍仅storage/scripting及公众号、组织Web两个host，无cookies/debugger/全局tabs。logo.png只向公众号页面开放以显示后台浮层。卸载扩展删除插件本地快照，但不影响Web原稿或后台已创建内容；重装后需重新发送。

## 使用

1. 在Web完成文字排版，直接点击“发送到公众号”。自动提取正文H1为标题，缺失则使用“未命名文章”，不再另填标题或确认任务。
2. 当前内容交给插件后，自动打开发送反馈和插件面板。插件使用已选有效公众号，首次默认第一个可用账号，自动独立新建图文并插入。
3. 没有已登录账号时，用并排小按钮打开公众号后台，登录后点击公众号下拉右侧的刷新图标；未启动快照自动继续。可提前在面板选择公众号，后续发送优先使用该选择。
4. 在插件打开的新图文中核对标题、正文、头尾和排版，补充封面/摘要等信息，手动保存并重开确认。

没有确认checkbox、手动启动、取消或恢复清理按钮，没有发送状态检测/轮询。插件只在打开/刷新/选择时读取账号与页面能力；后台浮层收到一次性插入成功或失败提示。Chrome无法自动打开popup时会打开本地面板标签，也可点击工具栏图标。

接收后Web修改不会改变插件快照。再次点击发送自动更新旧快照，正在执行时提示稍后发送。中断不会自动重放；如再次发送，应先查看后台是否已创建/插入内容。标题超过64个Unicode字符时需调整正文H1；含图片整篇使用既有“复制到公众号”。

## 失败处理

- 无插件/权限/版本不兼容：检查安装及站点访问权限，两端同时更新，复制流程仍可用。
- 没有账号：登录后台首页或草稿箱再刷新；已有编辑页不作为自动新建起点。
- 接收超时：查看后台是否已产生内容，插件没有自动重试。
- 非空编辑器、账号变化、入口/JSAPI缺失或超时：停止自动写入，检查后台一次性提示，必要时使用复制。
- 插件更新/浏览器中断：不自动重放旧执行，检查实际后台页面后从Web明确重新发送。
- 存储格式无法识别：Web原稿保留，重新安装插件后发送。
- 24小时到期：快照/回执在读取或命令时删除，重新发送当前内容。
