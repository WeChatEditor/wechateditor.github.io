# 静态部署

执行pnpm build，发布apps/frontend/dist整个目录（含assets）。Vite base为./，支持根路径和子路径，不依赖服务端路由回退。不要直接用file://打开；使用本地preview或静态HTTP服务。

生产使用独立HTTPS origin，不能与源应用同origin只换路径来隔离浏览器数据。剪贴板需要安全上下文；127.0.0.1开发环境可用于人工预览。CORS图片失败沿用产品诊断，不以服务配置承诺任意远程图可复制。

本阶段平台和域名未定，不自动发布。部署前确认HTTPS/base/缓存和实际资源请求；建议HTML及时刷新、哈希assets长期缓存。根/子路径及功能由维护者验收，验证证据在实施计划。
